# Lead Follow-Up Board™ — Day 04

A local-first browser board that makes follow-up state visible after prioritization: **NEW → WAITING → DUE → WON / LOST**.

## Live demo
https://braiz-works.github.io/ubuildos-completion-receipt-005/

## What it proves
- explicit deterministic stage movement
- due dates and overdue treatment
- editable local notes
- deterministic local CSV export
- synthetic-only reset state

Open the live demo above or `index.html` locally. No account or network service is required.

**Data warning:** do not enter confidential, customer-private, credential, regulated, or other sensitive data.
